## HACS-Integrationen

> *Hier findest du meine HACS-Integrationen – weil HACS auf GitHub lebt. Der Rest meiner Arbeit lebt auf meiner eigenen Forge (GitLab), weil ich nach einer willkürlichen Sperre ohne Vorwarnung entschieden habe, meine Infrastruktur selbst zu kontrollieren.*

Dieser Account ist der Anlaufpunkt für meine Home-Assistant-Integrationen. Sie sind für Menschen gemacht, die ihr Smart Home lokal, nachvollziehbar und nach den eigenen Vorstellungen betreiben möchten.

## Unabhängig bauen

Software sollte nicht davon abhängen, ob eine Plattform ein Konto ohne Vorwarnung abschaltet. Deshalb gehört die Infrastruktur dahin, wo sie kontrollierbar bleibt: in eigene Hände.

GitHub nutze ich gezielt dort, wo es für das Ökosystem sinnvoll ist – hier für HACS. Für alles andere setze ich auf eine eigene Forge.
